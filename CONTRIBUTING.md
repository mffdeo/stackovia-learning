# Contribuindo

## Como contribuir

- **Erros de conteúdo:** abra uma issue descrevendo o problema (página, seção, erro).
- **Traduções:** abra uma issue antes de começar qualquer tradução para alinhar o escopo.
- **Sugestões editoriais:** abra uma issue com a sugestão e o raciocínio por trás dela.

## O que não aceitamos por PR

- Alterações de conteúdo conceitual (isso é decisão editorial).
- Adição de novos capítulos (o conteúdo vem do repositório de autoria privado).
- Mudanças na stack principal da série.

## Código de conduta

Seja direto, respeitoso e honesto. Sem paternalismo. Sem julgamento por nível técnico.
